Este é um aplicativo de bloco de notas que permite criar e excluir anotações de forma simples e prática. Além disso, o usuário pode criar e remover tópicos para organizar melhor seu conteúdo.

O aplicativo também possibilita sair da conta atual ou excluir a conta do usuário quando desejado.

Como diferencial, a aplicação conta com uma Inteligência Artificial integrada, capaz de criar tópicos e anotações automaticamente, além de excluir a conta do usuário quando solicitado.
